# Bánh Nhà Phúc – trang web tiệm bánh

Trang web một trang (chỉ một file `index.html`), không cần máy chủ, đưa lên mạng miễn phí bằng GitHub Pages.

## Sửa thông tin tiệm

Mở `index.html`, tìm phần `THÔNG TIN TIỆM` ở cuối file:

- `phone`: số điện thoại của tiệm, ví dụ `"0912345678"`
- `zalo`: số Zalo (để trống nếu trùng số điện thoại)

Danh sách bánh và giá nằm ngay bên dưới, trong `CAKES`. Mỗi bánh có 3 giá theo cỡ 16cm, 20cm, 24cm.

## Việc còn lại

- Thay giá tạm bằng giá thật
- Thay hình vẽ minh họa bằng ảnh bánh thật của tiệm
- Điền số điện thoại / Zalo
